# 蒼空解放資料網

《蒼空解放》（蒼空のリベラシオン／Liberasion of Azure）是日本 SEGA 開發與推出的 2D 動作 RPG 手機遊戲。

本網站整理遊戲關閉前(2017/8/30)的角色、裝備、關卡與故事等資料，提供繁體中文查詢介面。

**[前往蒼空解放資料網](https://catchtest.github.io/Sokulibe-Data/)**

## 本機瀏覽

網站由 HTML、CSS、JavaScript 與 JSON 資料組成，不需要編譯。下載專案後，在專案根目錄使用 Python 3 啟動靜態伺服器：

```sh
python -m http.server 8000 --bind 127.0.0.1
```

開啟 [本機網站](http://127.0.0.1:8000/index.htm) 即可瀏覽。部分前端套件由 CDN 載入，瀏覽時需保持網路連線。
